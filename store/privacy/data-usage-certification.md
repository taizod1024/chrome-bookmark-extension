# Data usage certification

Check the box: "I certify that my data usage complies with the Developer Program Policies."

Basis:
- No user data is collected, transmitted, sold, or shared with any third party.
- Data used (bookmarks, tab titles) is processed locally in the browser only.
- Preferences (columns, rows, display flags) are stored locally via localStorage.
- Data-type checkboxes: leave all unchecked.
